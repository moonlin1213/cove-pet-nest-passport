# Cove灵宠屋 · FoloToy 版

把一只灵宠带到 FoloToy AI Passport 上。平时它在自己的小窝里伸懒腰、眨眼、打盹，按一下 OK 才会打开菜单。

## 第一次安装

准备一台 **FoloToy AI Passport（ESP32-C3、8 MB）**、一根能传文件的 USB 数据线，以及装有 Chrome 或 Edge 的电脑。第一次体验不用安装 Python，也不用先搭服务器或配 Wi-Fi。

1. 点亮挂件，接上电脑。打开上面的安装页，点 **首次安装**，在浏览器弹窗里选 Espressif 或 USB JTAG/serial 设备。
2. 页面读完原机内容后，点 **保存备份并安装**，在电脑上选一个能找回的位置，保留默认文件名。安装会替换挂件上的程序和存档；页面会先验证备份，再写入。备份可能含原有网络配置，只保存在自己的电脑。
3. 保持连接直到页面显示校验完成。挂件重启后用 **▲ / ▼** 在团团和麦麦之间挑选，按 **OK** 确认同行。以后开机会记住上次的伙伴。

端口列表为空时，先换一根确认能传数据的线，关闭串口工具，直接接电脑再试。安装中断可以重新连接；要找回原有的应用与存档，在同一台挂件上点 **恢复原机备份**，选第一次安装前保存的原名文件。恢复会覆盖备份之后的变化。再次安装前请另存备份。

## 带它出门

| 想做什么 | 怎么按 |
| --- | --- |
| 看宝宝自己活动 | 待在全屏小窝。不同性格和心情会影响姿势与停留时间 |
| 喂食、陪玩、摸摸 | 短按 OK，▲ / ▼ 选动作，再按 OK |
| 洗澡、清理便便 | 菜单里选相应动作。便便出现时待机会显示宠物名字和提示，按 OK 直接去清理，▼ 可稍后处理 |
| 去看想你的灵宠 | 待机出现名字和「想你啦」时短按 OK。照顾算给正在探望的它；长按 OK 或等待自动退出，就回到原伙伴 |
| 看看它的小心思 | 菜单里选「看看它的小心思」，跟着提示藏星星、击掌或慢慢呼吸 |
| 找回溜出去的宝宝 | 空窝时按 OK，默认选中「召唤」，再按 OK |
| 查看成长 | 短按 OK 打开菜单，在宠物名字下方查看当前成长值 |
| 设置息屏 | 菜单翻到「息屏」，按 OK 在 30 秒、1 分钟、5 分钟和常亮之间切换。默认 1 分钟，息屏后任意键第一次只唤醒 |
| 收起菜单 | 长按 OK 约 0.8 秒，或在普通菜单等约 18 秒 |

**示例小窝**可以拔线离线玩。两只宝宝共享 12 粒起始口粮，喂一口用一粒，陪玩一次补一粒。示例照顾和成长保存在挂件本地。每累计 60 分钟开机同行，当前灵宠额外长 1 点，每只每天最多 4 点。每天前三次成功喂食、陪玩或安抚各再加 1 点。换宠后，没满一小时的余量留给原来的伙伴。示例版用累计开机的每 24 小时作为一天。

**带自己的灵宠**时，电脑上的公开版灵宠屋负责粮仓、照顾记录和成长。出门断网时也能喂、玩和安抚，挂件按宠物记下动作和同行时长；息屏照常计时，关机暂停。回到家庭 Wi-Fi 并启动电脑上的新版灵宠屋后，按小屋当地日期结算到原来的成长值，同一条记录重试只算一次。互动立即保存，同行时长约每五分钟存一次。初次配对后先在家连上小屋校时，再带出门。宠物孵化、换阶段或新领养后，重新同步图集即可。[连接自己的公开版灵宠屋](docs/pair.md) · [灵宠屋主项目](https://github.com/moonlin1213/cove-pet-nest)

亲密度按每只灵宠分别积累。亲密度达到 20 后就有机会主动想你，越亲越容易。整台挂件两次想念至少隔 2 小时，同一只至少隔 6 小时。个人小屋更新到 v0.3.1 后，可同步离线获得的亲密度。刷整机前，先回家同步并按网页提示保存备份。
