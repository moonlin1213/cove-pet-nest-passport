# Cove灵宠屋 · FoloToy 版

把自己在灵宠屋养的那只宝宝，带到 FoloToy AI Passport 上。出门前选好今天想带的伙伴，平时屏幕就是它的小窝，按一下 OK 才打开菜单。

## 挂件上怎么玩

- **选一只宝宝出门。** 在菜单里换伙伴，下次开机还能见到上次选的那只。
- **看看它在干什么。** 宝宝会眨眼、趴下或打盹。六维性格和当下心情会影响动作和停留时间；有时它会偷偷溜出去，按 OK 打开菜单，再按一次「召唤」就能叫它回来。
- **亲手照顾它。** 喂一口、摸摸它，或者看看它的小心思，陪它藏星星、击掌、一起慢慢呼吸。

## 项目进度

上述玩法已在连接开发版 Cove 的 AI Passport 真机上运行。这个独立仓库目前提供项目介绍；面向公开版灵宠屋的接口适配、图集同步工具和安装包仍待发布。

宠物、粮仓、成长和相册由灵宠屋保存。首版适配要打通的是：在自己的灵宠屋领养宝宝，在挂件上选中它，拔掉 USB 后通过 Wi-Fi 喂一口，再到网页看到主人的这次照顾和对应的粮数。
