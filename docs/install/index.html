Cove灵宠屋 · FoloToy 版

用 USB 数据线把 FoloToy AI Passport 接到电脑，点亮屏幕。请确认它是 ESP32-C3、8 MB 的 AI Passport。

用桌面 Chrome 或 Edge 点「连接挂件」，在弹窗里选择 USB JTAG/serial debug unit 或 Espressif 设备。只插这一个挂件会更容易辨认。

安装会替换挂件现有内容。页面先把整机备份保存到你的电脑，里面可能有原来的配网信息，请自己保管。安装时保留默认文件名。

没有看到挂件或连接失败？

先试一根能传文件的数据线，直接接电脑，关闭其他串口工具和占用挂件的网页。拔插后再点连接；端口列表里选好设备，再点弹窗里的连接按钮。
