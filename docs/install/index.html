Cove灵宠屋 · FoloToy 版

带上自己养的灵宠

启动这台电脑上的灵宠屋，插上挂件，在本机小屋里挑选今天的伙伴。请使用桌面 Chrome 或 Edge。

小屋打不开，或使用了其他端口？

若浏览器提示无法访问，先打开原来的小屋。旧版小屋（如 v0.2.0）需从灵宠屋发布页下载 Cove-Pet-Nest-Update.zip，解压并双击对应系统的启动器，按提示沿用原来的数据目录。更新并启动后，再点上方按钮。

首次安装挂件

用 USB 数据线把 FoloToy AI Passport 接到电脑，点亮屏幕。此固件适用于 ESP32-C3、8 MB 的 AI Passport。

点「连接挂件」，在弹窗里选择 USB JTAG/serial debug unit 或 Espressif 设备。只插这一个挂件会更容易辨认。

安装会替换挂件现有内容。页面先把整机备份保存到你的电脑，里面可能有原来的配网信息，请自己保管。安装时保留默认文件名。

没有看到挂件或连接失败？

先试一根能传文件的数据线，直接接电脑，关闭其他串口工具和占用挂件的网页。拔插后再点连接；端口列表里选好设备，再点弹窗里的连接按钮。
