# 带上自己养的宠物

## 第一次连接

1. 在电脑上启动自己原来的公开版灵宠屋。旧版用户（如 v0.2.0）先从灵宠屋发布页下载 **Cove-Pet-Nest-Update.zip**，解压，双击适合自己系统的启动器，按提示沿用原来的小屋和数据目录。[灵宠屋发布页](https://github.com/moonlin1213/cove-pet-nest/releases/latest)
2. 把 FoloToy AI Passport 点亮，用 USB 数据线连接电脑。在桌面 Chrome 或 Edge 打开安装页，点 **连接我已有的灵宠屋**。如果挂件还是原厂系统，先在安装页点 **首次安装**，保存原机备份、完成固件安装后再配对。[中文安装页](https://moonlin1213.github.io/cove-pet-nest-passport/install/)
3. 进入本机配对页后，如有提示，使用原小屋的本机访问码登录。选择想带的宠物，按页面提示授权 USB 设备、填写家庭 2.4 GHz Wi-Fi 并写入。宠物名单、图集和 Wi-Fi 信息在自己的电脑与挂件之间处理。
4. 等待页面确认校验完成后再拔线。保持电脑上的小屋运行，挂件在同一家庭 Wi-Fi 下喂食或陪玩一次，就能在原小屋核对照顾记录。配对页面可以关闭。

出门后的离线照顾与同行时间会在回家后同步。换宠、领养新宠或更新成长阶段图集时，回到配对页面再连一次 USB。重新配对或整机安装前，请先让挂件在家同步。整机安装会覆盖挂件现有数据，电脑上的原小屋使用原数据目录。

## 遇到问题

- **浏览器提示无法访问。** 在这台电脑上打开灵宠屋，再回安装页点一次按钮。使用自定义端口时，展开安装页的「小屋打不开，或使用了其他端口？」，输入原小屋端口。默认是 8767。
- **打开小屋后显示 404 或找不到页面。** 这是旧版小屋常见的表现。使用上面的图形更新工具升级原小屋，启动新版后再连接。
- **看不到 USB 设备或提示端口占用。** 检查挂件已点亮，使用可传输数据的线。关闭其他使用该挂件的网页、旧版连接助手和串口工具，再到本机配对页重试。同步服务使用家庭局域网；防火墙咨询时只选择自己的可信家庭网络。
- **没有可选的宠物。** 在原小屋里确认至少有一只已就绪的伙伴，并确认本次打开的是原来的数据目录。

## 旧版命令行配对

<details>
<summary>仍在维护公开版小屋 v0.2.0 的高级用户</summary>

保留旧版小屋时，可以继续使用独立连接助手。本地连接助手目前需要 Python 3.11 或更新版本。电脑与挂件须在同一可信家庭网络，挂件用 2.4 GHz Wi-Fi。

1. 先在电脑启动公开版小屋（默认本机端口 8767），用浏览器领养至少一只已有形象的宝宝。保持小屋运行。
2. 在本仓库点 **Code → Download ZIP**，解压，打开该文件夹里的终端。先在网页上完成示例版安装，然后关闭安装网页或断开串口。
3. 为连接助手建一个独立环境，然后运行配对。macOS 或 Linux 使用下面三行。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python companion.py --pair
```

Windows PowerShell 使用下面三行。

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe companion.py --pair
```

助手会询问电脑的局域网 IPv4 地址、要带的宠物和 Wi-Fi。电脑的地址可以在系统的网络设置中查看。用 USB 数据线连接一台挂件，再选择伙伴编号；多只用英文逗号分隔。Wi-Fi 密码输入时不会显示。助手把当前形象和配对信息写到挂件，再启动家庭网络连接服务。上传时保持线缆连接。

保持助手窗口与原灵宠屋运行，即可拔线，从挂件喂一次，再打开网页核对粮仓和照顾记录。电脑防火墙询问时仅对可信家庭网络允许 TCP 8768。挂件和电脑之间使用带配对凭据的局域网 HTTP。不要将这个端口转发到公网。灵宠屋的网页登录凭据只由本机助手使用。

以后在这个目录运行上面第三行，去掉 `--pair` 即可。换 Wi-Fi、换选中名单或同步新阶段图集时再接 USB，用 `--pair`。启用新图集前会检查文件与是否有待确认的照顾。正式小窝的口粮和成长以电脑回执为准。升级到挂件 v0.2.0 时，也请从同一版本启动连接助手。联网后助手会将离线记录补进当前小屋的数据目录，并按 PET_NEST_TIMEZONE 结算每日上限（默认上海时间）。助手和小屋应使用同一数据目录与时区。重新配对或整机安装之前，请先让旧挂件回到家庭网络同步。整机重装后需要重新配对。无法确定日期的离线重启记录会保留，不把关机时间算作陪伴。

自定义数据目录可用 `--data`，小屋端口可用 `--core-port`，多个串口时可用 `--device` 指定。Linux 构建中文菜单需要 Noto Sans CJK；也可以用环境变量 `PASSPORT_FONT` 指向本机支持中文的字体。个人数据目录里的 `passport-bridge.json`、整机备份、个人形象和网络配置请勿公开。

</details>
